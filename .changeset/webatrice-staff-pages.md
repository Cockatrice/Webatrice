Staff pages from desktop Cockatrice: Administration, Moderation, Card Art Rules and Developer.

Administration (moderators; server functions for admins only) updates the server message, shuts the server down with a reason and delay, reloads the configuration, grants replay access, force-activates accounts (moved here from the Logs page), and has desktop's Lock / Unlock safety toggle, which, while locked, also hides the moderator section of user context menus and the in-game moderator powers (Kick from game for a non-host, talking as a spectator where the game forbids it). An unlocked moderator, or the game's judge, can now talk as a spectator, as on desktop. On Cockatrice 3.1 servers, Moderation investigates a user (account info, alts, sessions), lists staff last logins, resets a password (admins; the temporary password is shown once and never stored) and removes an avatar; Card Art Rules lists, adds (with or without a provider id) and removes card-art rules; Developer shows live server statistics to developers. User context menus gain "Investigate user" on 3.1 servers. The pages are listed in the user menu for the roles that can use them, and the 3.1 pages stay hidden on older servers.
