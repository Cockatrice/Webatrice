Moderators and admins get desktop's moderator section on every user context menu — room and server user lists, chat author names, the Player page and the game's player list: warn (with the server's official warning reasons), ban (by name, IP and client id, permanent or timed), warn and ban history, admin notes, and for admins promote/demote moderator, judge and (on 3.1 servers) developer. Warning reasons show their recommended intervention level, as desktop does, on servers that send one. The moderator log search gains desktop's date range, maximum results and empty/failed result messages, and the Logs page hosts the moderator functions to grant replay access and force-activate an account.
