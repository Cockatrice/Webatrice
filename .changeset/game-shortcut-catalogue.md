Adds the rest of desktop's game shortcuts (75 new actions) and groups the Shortcuts settings tab the way desktop does (Card Counters, Player Counters, Power and Toughness, Game Phases, Playing Area, Move Selected Card, View, Move Top Card, Move Bottom Card, Gameplay, Drawing, Hand). New actions include tap / untap, play and play face down, create all related tokens, moving the selection to exile, hand, top of library or battlefield, viewing the hand and exile, sorting and revealing the hand, every top- and bottom-of-library move, shuffling the top or bottom cards, the D / E / F card counters, life and mana-pool counters, the P/T flows and setting a phase directly. Desktop keys the browser keeps for itself are remapped: Create all related tokens is Ctrl+Shift+K (desktop Ctrl+Shift+T), and add / remove life are Shift+F12 / Shift+F11 (desktop F12 / F11). The direct phase actions ship unbound, because desktop's F5-F10 reload the page or drive the browser. Most new actions are unbound, as on desktop, and the menus show each action's current key. The card menu gains "All tokens" when a card has more than one related token. The move-to-graveyard and move-to-bottom-of-library shortcuts now also move selected hand cards, as desktop's do. Create all related tokens now follows desktop: it skips relations cards.xml marks `exclude` (an empty attribute included), asks how many when the one token it creates has an "x" count, and "Create another token" then repeats it, built from the token's card. Moving cards onto the battlefield from the hand, the stack, the library or a zone view lets the server pick the column, stacking a card on a pile of the same name; moving selected cards there places each card in its cards.xml row with its printed P/T, tapped when it comes into play tapped; moving several cards to the top or bottom of the library shuffles them there so their order stays hidden. Tap / Untap flips each selected card.
