Five more desktop settings. General › Startup tab chooses where the first login after opening Webatrice lands: Deck Storage, Game Replays, the server lobby (the default, as before) or a Server Room opened by name, optionally only on one server; reloading the page, reconnecting and signing in again return to the page you were on. General › Version can tell you, once per server, when the server supports features this Webatrice does not. Chat › Enable mention completer suggests names as you type `@` in room, private and game chat, chosen with the arrow keys and inserted with Enter or Tab. User Interface › Replay sets the buffer time that merges quick backward skips into one rewind. Decks opened from My Decks now each get their own tab, as on desktop, and the deck editor gains Open deck…; User Interface › Open deck in new tab by default decides whether that opens in a new tab or replaces the deck being edited, which asks to save, discard or open in a new tab when the deck has unsaved changes. The Commander bracket estimate no longer sends your deck list to Commander Spellbook without asking: as on desktop, the first Commander deck you open asks whether to enable the integration (on request), make it automatic, or disable it, and User Interface › CommanderSpellbook integration changes the choice later.
